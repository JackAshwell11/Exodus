# Exodus

Survive a hostile, endless world, build yourself up from nothing, and escape by constructing a rocket at a fixed site.

## Highlights
- Top-down survival and progression in a procedurally generated world.
- Distance-based difficulty and rewards; preparation beats reflexes.
- Base building, crafting, and logistics-focused endgame.
- Guided objectives without forcing a linear path.

## Build
This project uses CMake (see `CMakePresets.json`) and Conan (`conanfile.py`).
